# Java static and final object

A Java console application.

## Tech stack

- Java
- Lombok

## Concepts covered

Console input (Scanner), static/final members.

## Project structure

- `src`: Disk, Main, Point

## How to run

Open the folder in IntelliJ IDEA or Eclipse and run the class that contains the `main` method.

The code uses Lombok annotations: add the Lombok library and enable annotation processing in your IDE.
